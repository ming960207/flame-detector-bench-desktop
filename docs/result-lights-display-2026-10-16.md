# 检测结果灯显示修复（2026-10-16）

现场问题：跳过继电器检测后结果灯空心；指示灯结果未显示。

原因：结果卡的独立脚本通过全局 fetch 改写读取实时 DIO，复位后的电平无法表达检测结果。摄像头提交还强制依赖继电器报告及 COMPLETE 进度，缺少相关状态时不提交；当天 09:15 批次日志未归档灯检结果。

修改：
- 结果卡使用同一批次接口返回的摄像头及继电器动作判定，不依赖实时 DIO。实时物理反馈接口保持可用。
- 继电器跳过仍保留两个结果灯，绿色通过样式；悬浮及无障碍提示均与正常通过一致，不显示跳过提示。记录中的真实检测证据不改写为 PASS。
- 指示灯与继电器结果通过为绿、失败为红、未取得结果为灰；按批次、槽位匹配，避免沿用上一轮结果。黄灯仅为视觉调试证据，不改变生产合格判定。
- 摄像头在预检完成后独立提交结果，不再要求继电器报告/进度；提交失败每秒重试，成功后同批次不重复提交。

验证：41 项相关回归通过；后端 TypeScript 构建、桌面前端生产构建通过。

现场验收：运行 update-current-version.cmd 更新 refactor/unified-backend 后重启；开启继电器跳过完成一轮，两个继电器结果灯应为绿色，提示仅显示通过。查看运行绿灯、火警红灯结果及悬浮提示；真实未取得证据仍显示待检测。新批次不得保留上一批次的灯检结果。硬件摄像头与 PLC 联机效果仍需现场验证。

# 火焰探测器检测台上位机操作人员操作指南

| 项目 | 内容 |
| --- | --- |
| 适用对象 | 检测台操作人员、现场检验人员 |
| 适用软件 | 火焰探测器检测台现场只读监测版 |
| 适用设备 | PLC 检测台及 6 台火焰探测器 |
| 文档版本 | V1.0 |
| 编制日期 | 2026-08-21 |

## 1. 使用边界与重要提示

当前软件是现场只读监测版，主要用于：

- 读取并显示 PLC 当前工序、运行状态、安全链和报警状态；
- 读取 6 台火焰探测器的通信状态、实时波形、探头数据和火警响应；
- 在热源、爆闪和电磁干扰等工序期间自动采集波形并计算检测指标；
- 显示每台探测器的 A 类合格、B 类合格、不合格或待判定状态。

软件不会直接控制检测台动作，也不能替代现场 HMI、实体按钮或急停回路。启动、停止、复位和急停必须按照现场安全规程在实体控制设备上完成。软件主界面显示“通信正常”，只表示数据通道正常，不表示可以跳过开机检查或安全确认。

严禁通过任何方式旁路安全门、限位、急停或其他安全保护。出现人身、机械、火焰、强光或电气风险时，优先使用现场实体急停，并通知班组长或设备维护人员。

## 2. 开机前检查

开机前逐项确认：

| 检查项目 | 合格要求 |
| --- | --- |
| 作业区域 | 检测台周围无人停留，夹具、热源、爆闪灯和电磁干扰区域无异物；防护措施已到位。 |
| 电源与控制 | 检测台、PLC、探测器及通信设备电源正常；实体急停已按现场规定复位。 |
| 探测器安装 | 6 台探测器安装牢固，编号与工位对应，线缆和接头无松脱、破损。 |
| PLC 通信 | 上位机与 PLC 的现场网络连接正常，PLC 处于允许检测的状态。 |
| 安全链路 | 防护门、限位、急停和其他安全条件均正常，不得以软件显示替代实体确认。 |
| 工件/批次 | 待检产品已按工艺要求放置并固定，批次或产品信息已按现场流程登记。 |

## 3. 启动软件

### 3.1 现场安装版

1. 双击桌面或开始菜单中的“火焰探测器检测台”。
2. 等待主界面显示完成，观察右上角通信状态。
3. 正常状态应显示“通信正常”；工序区域应逐步显示 PLC 工序，底部状态应显示探测器在线数量。
4. 如果显示“等待连接”，先等待约 30 秒，再点击右上角的刷新按钮一次。
5. 刷新后仍显示“等待连接”“PLC 未接入”或“等待 PLC / 探测器数据接入”时，不得启动检测，联系设备维护人员检查电源、网线、PLC 和探测器通信。

如果现场没有桌面或开始菜单快捷方式，不要自行运行开发脚本、修改通信参数或复制配置文件，应联系维护人员处理。

### 3.2 退出软件

检测正在进行时不要关闭窗口、结束进程或重启工控机。确认流程已完成或已按现场规程安全中止、设备已停止后，再关闭软件窗口。软件异常退出后，不要直接重复启动检测，先确认机械位置和安全状态。

## 4. 正常检测操作

上位机只负责监测和判定显示，检测动作由现场 HMI 或实体控制设备发起。

1. 在现场 HMI/实体控制设备上确认设备处于待机、安全就绪状态。
2. 确认上位机顶部显示“通信正常”，并确认 6 台探测器均已建立通信。未达到现场规定的在线数量时，不得放行产品。
3. 按现场工艺要求在 HMI/实体控制设备上启动检测。
4. 检测过程中观察上位机的当前工序、报警信息、探测器卡片和波形状态。不要反复点击刷新，也不要在检测过程中修改通信参数或判定阈值。
5. 等待工序流程到达“流程完成/已完成”，再查看检测结果。单台探测器显示 PASS 或合格，不代表整台检测台流程已经完成。
6. 按质量管理流程记录或处理最终结果。出现不合格、故障或待判定时，不得直接放行。

### 4.1 工序流程

主界面的“工序流程”按以下顺序显示进度：

1. 等待启动；
2. 初始位垂直复位；
3. 初始位确认；
4. 检测区 1 定位；
5. 热源位夹具下压；
6. 热源干扰测试；
7. 热源后夹具上升；
8. 检测区 2 定位；
9. 爆闪位夹具下压；
10. 五次爆闪测试；
11. 电磁干扰；
12. 回初始位确认；
13. 流程完成。

已完成的节点会显示为完成状态，当前节点会高亮。当前节点出现告警或中止标记时，应先确保现场安全，再按异常处置流程处理。

### 4.2 波形采集过程

工序开始后软件自动记录无干扰噪声；在热源、爆闪和电磁干扰阶段自动计算干扰比值及相关波形指标。操作人员不需要手工开始采样或停止采样。

“实时波形监视”默认可以收起。需要查看时点击该区域展开，再点击底部的探测器编号切换查看对象。波形显示“等待探测器通讯”“等待波形”或采样点数不足时，只能视为数据未准备好，不能视为合格。

## 5. 主界面识读

### 5.1 顶部状态栏

| 显示 | 含义与处理 |
| --- | --- |
| 通信正常 | 上位机与现场数据通道在线，可继续观察 PLC 和探测器状态。 |
| 等待连接 | 数据通道未建立或已断开；等待后刷新一次，仍未恢复则联系维护人员。 |
| 刷新按钮 | 重新读取当前状态。它不是停止、复位或重新启动检测的按钮。 |
| 详情 | 打开六路波形、通信详情、只读自检和受维护人员控制的配置入口。 |

### 5.2 PLC I/O 与继电器

该区域显示输入/内部状态、自动/报警状态和输出继电器状态。绿灯表示对应信号处于有效状态，灰灯表示当前未有效；报警状态可能显示红灯。操作人员重点关注安全链、停止/中止、安全限位和流程报警，不要根据某一个 I/O 灯单独判断整机是否安全。

### 5.3 报警信息

报警信息区域通常包含以下项目：

- PLC 通信：显示数据通道是否在线；
- 流程状态：显示当前工序及工序码；
- 安全链：显示安全输入和安全条件；
- 停止/中止：显示停止请求或停止锁存状态；
- 安全限位：显示安全限位状态；
- 结果分级：显示当前检测分级及 6 台探测器的在线、火警、故障数量。

出现“报警”“故障/中止”或红色状态时，不要仅通过刷新页面消除提示。先确认现场是否需要急停，再由维护人员检查原因。

### 5.4 探测器实时状态卡片

每台卡片显示探测器编号、地址、三/四波长类型、波形、探头数据、探头比值、噪声 RMS、干扰比和采样数量。

常见状态如下：

| 状态 | 含义 |
| --- | --- |
| 采集中 | 已在线，正在接收或处理实时数据。 |
| PASS | 当前已通过相应分析判定，但仍需等待整套 PLC 工序完成。 |
| FAIL | 当前探测器或定量指标未通过，应查看不合格原因。 |
| 离线 | 未收到探测器有效通信，不得按合格处理。 |
| 待判定 | 数据或工序尚未完成，不能放行。 |

火警数量表示探测器对当前测试刺激的响应数量，不等同于探测器故障数量。最终放行应同时参考工序完成状态、全部启用探测器结果和报警信息。

## 6. 结果判读

### 6.1 分级含义

- A 类合格：各项指标满足较严格的 A 类限值；
- B 类合格：未达到 A 类，但满足 B 类限值；是否按 B 类放行，仍须遵守现场质量规程；
- 不合格：超过 B 类限值、设备故障或其他质量门禁未通过；
- 待判定：工序未完成、采样不足、通信未连接或分析数据尚未齐全。

主界面下方的汇总卡片分别统计“当前 A 类合格”“当前 B 类合格”和“当前不合格”。局部卡片出现 PASS、在线或火警，均不能替代“流程完成”和整批结果确认。

### 6.2 常见不合格原因

不合格卡片下方会显示原因，常见原因包括：

- 探测器故障或离线；
- 波动噪声值或绝对噪声值超过上限；
- 干扰比超过上限；
- 一致性趋势低于下限；
- P2/P1、P2/P3、P3/P1 等探头比值低于或高于设定范围；
- 采样数据不足或关键指标缺失。

出现不合格时，记录探测器编号、当前工序、界面显示的具体原因和发生时间，按质量流程进行隔离、复检或维修。不得通过修改阈值来替代产品复判。

## 7. 详情与只读自检

### 7.1 查看详情

点击右上角“详情”，可进入“六路波形与通信详情”。该页面用于查看 6 台探测器的完整波形、探头原始/归一化数据、SNR 比值和工序分析阶段。

### 7.2 设备只读自检

设备只读自检应由经过培训的人员在设备空闲且通信稳定时执行。点击“设备只读自检”后，软件会按设备顺序执行 7 项检查：

1. 连接检测；
2. 版本读取；
3. 参数检测；
4. 状态监控；
5. 实时数据；
6. 镜面检测；
7. 生成报告。

自检期间不要重复点击按钮、拔插通信线或修改配置。完成后显示“全部启用设备通过”才表示本次只读自检通过；出现失败项目时，记录设备编号和失败信息并联系维护人员。只读自检不是生产检测流程的替代品。

### 7.3 通信与显示配置

“通信与显示配置”涉及通信模式、IP/串口、端口、设备地址、三/四波长协议、波形显示方式、采样点数和判定阈值。保存配置会重启探测器连接并写入本机运行配置。

该入口仅供设备维护、调试或经授权的工艺人员使用。操作人员不得擅自修改配置；如确需修改，应由授权人员记录修改前后的参数，并在保存后确认所有探测器重新上线。

## 8. 异常处置

| 界面现象 | 操作人员处理 |
| --- | --- |
| 等待连接 / PLC 未接入 | 不启动检测；等待约 30 秒后刷新一次。仍未恢复，检查设备电源和网线并联系维护人员。 |
| 探测器离线或在线数量不足 | 检查对应探测器电源、线缆和通信设备。检测进行中不要直接拔线；先按现场规程安全停止。 |
| 故障/中止、流程报警 | 确认人员和设备安全；需要时使用实体急停或实体停止；记录报警时间和当前工序，联系维护人员。 |
| 安全链报警 / 安全限位报警 | 立即停止继续操作，不得旁路、强制复位或反复启动，等待维护人员确认安全条件。 |
| 流程长时间停在某一步 | 不要连续点击刷新或关闭软件；保持现场安全，记录当前步骤和时间，联系维护人员检查机械、PLC 和限位。 |
| 波形不足 / 待判定 | 不按合格处理。确认通信、工序和采样状态，必要时由维护人员重新初始化或安排复检。 |
| 检测结果不合格 | 记录探测器编号、工序和具体原因，按质量流程处置；不得仅通过修改阈值放行。 |
| 软件启动失败或界面空白 | 不自行运行开发命令或替换文件，保留错误提示并联系维护人员。 |

异常恢复后，必须同时确认：

- 安全链路恢复正常；
- PLC 工序状态重新同步；
- 探测器通信和波形恢复；
- 当前检测批次是否仍然有效。

如果无法确认当前批次是否有效，应按现场质量流程重新判定，不得用异常前的局部结果直接放行。

## 9. 交班与关机

1. 确认检测台已完成流程或已按规定安全中止，机械部件处于安全位置。
2. 按现场记录要求登记检测结果、异常现象和处理情况。
3. 将不合格或待判定产品按质量流程标识和隔离。
4. 确认无人员处于危险区域后关闭上位机软件；设备总电源按班组或设备规程处理。
5. 将未解决的通信、报警或配置问题写入交班记录并通知下一班和维护人员。

## 10. 操作员快速检查表

### 开始检测前

- [ ] 作业区域和防护措施正常；
- [ ] 检测台、PLC、探测器和通信设备已上电；
- [ ] 上位机显示“通信正常”；
- [ ] 6 台探测器在线数量满足现场要求；
- [ ] 无安全链、停止/中止、安全限位和流程报警；
- [ ] 产品/批次已按工艺要求准备；
- [ ] 已在实体 HMI/控制设备上确认可启动。

### 检测完成后

- [ ] 工序流程到达“流程完成/已完成”；
- [ ] 所有探测器均不是“离线”或“待判定”；
- [ ] 检测结果和分级已确认；
- [ ] 不合格原因已记录并按质量流程处理；
- [ ] 异常和交班事项已记录。

## 11. 名词说明

| 名词 | 说明 |
| --- | --- |
| PLC | 可编程逻辑控制器，负责检测台工序和设备状态。 |
| SNR | 探头信号比值，用于反映不同探头信号之间的关系。 |
| RMS | 均方根指标，用于评价波动噪声水平。 |
| EMC | 电磁兼容/电磁干扰测试阶段。 |
| A 类、B 类 | 按当前配置限值划分的质量等级。 |
| 只读监测 | 上位机只读取和分析现场数据，不直接写入 PLC 输出或控制检测台动作。 |

本指南只说明当前现场只读监测版的操作界面。涉及电气安全、机械安全、产品放行、复检、维修和数据留存时，以企业正式工艺文件、设备安全规程和质量管理制度为准。

# 测试数据导出

在项目根目录双击 `导出当天测试数据.bat`，工具以北京时间确定当天日期，从 `config/release-source.json` 的 GitHub 地址和分支获取已上传归档，保存原始日志并生成 Excel。输出位于 `test-log-exports` 下的时间戳目录；每次运行新建目录，不覆盖已有结果。

运行环境需要 Git、Node.js、项目 ExcelJS 依赖，以及可访问该 GitHub 仓库的网络和 Git 凭据。更新脚本会检查并补齐 ExcelJS。获取的范围为运行时已上传到配置分支的归档，现场未上传的数据无法包含；测试完成时间取自日志正文，归档时间用于选择当天归档。

也可在项目根目录通过命令行导出指定日期：

```powershell
node scripts/test-log-export.mjs --date 2026-11-20
```

Excel 包含噪声数据、工序比值、批次索引和数据说明，均保留测试完成时间。日志格式不完整、Git 拉取失败或 Excel 生成失败时会报错，不会当作成功导出。

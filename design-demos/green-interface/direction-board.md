# 浅绿色界面三方向初稿

三版均以用户提供的主题图为业务参考：顶部品牌与标题、左侧 PLC I/O、中部检测台和探测器状态、右侧报警/结果、底部工序流程。差异在信息层级、布局骨架和绿色的使用方式。

## A · 清透序列

- 方向逻辑：结论优先的清透现场总览。
- 视觉特征：深松柏绿侧栏 + 暖白内容区，标题使用安静的衬线字，主设备作为运行状态卡的视觉锚点。
- 结构差异：纵向工作区导航，首屏先给“检测台可运行”结论，再给批次条目和链路状态。
- 适用感受：操作员每天长时间使用，信息不压迫，异常时容易定位。
- 截图：`green-interface-a.png`

## B · 苔原台

- 方向逻辑：把真实设备作为空间中心，以设备舞台组织左右证据。
- 视觉特征：大面积雾绿留白、极细结构线、中央实物图与深绿“现场裁决”侧板形成对照。
- 结构差异：无传统侧栏；主区域是“操作状态 + 设备照片 + 现场裁决”，底部横向承载批次和闭环工序。
- 适用感受：适合展示设备正在做什么，兼顾演示与现场值守。
- 截图：`green-interface-b.png`

## C · 翡翠指挥

- 方向逻辑：延续主题图的完整工业控制台信息密度，但把蓝色换成更克制的翡翠绿。
- 视觉特征：深绿顶栏、浅绿工作区、判定矩阵和数据条，减少大面积圆角与发光效果。
- 结构差异：上方结论横幅，左侧批次矩阵，右侧资产/PLC 事件，底部流程轨道，适合快速横向扫读。
- 适用感受：最接近现有主题图的生产级信息密度，适合直接作为后续深化母版。
- 截图：`green-interface-c.png`

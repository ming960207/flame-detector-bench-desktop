# 火焰探测器检测台 - 测试程序（PLC与数据状态监听）

本测试程序是针对火焰探测器检测台的**独立旁路监听与测试观察系统**，用于在主程序运行过程中，无侵入、只读地实时监听主程序的 PLC 流程状态、波形数据、继电器信号，并自动记录工序用时、判定依据与测试报告。

---

## 核心特性

1. **只读安全监听**：不直接占用 PLC 通信端口或串口，不向 PLC 发送任何控制写入指令，完全通过主程序提供的只读数据接口进行监听，确保现场主控流程的绝对安全。
2. **状态与波形同步**：实时捕获主程序各个工位（如上料、点火、通信、断电等阶段）的 PLC 状态、探测器波形数据、继电器切换状态。
3. **自动生成测试报告与归档**：
   - 每次工步循环或测试流程完成/中断后，自动输出详细结构化的 JSON 归档数据。
   - 自动生成 Markdown 格式的完整测试报告（含工序时序、阈值比对、判定依据）。
   - 自动在日志中追加单行紧凑测试结果，方便算法批量复盘。
4. **自定义测试阶段工步计划**：右上角齿轮提供只读参考主程序工步，并允许配置独立的观察阶段计划。

---

## 目录文件说明

- **`FlameDetectorTestProgram.exe`**：本目录中的单文件免安装独立版（开箱即用，内置运行时，直接双击运行）。
- **`一键启动测试程序(脚本版).bat`**：源码/脚本模式一键启动脚本。
- **`一键停止测试程序(脚本版).bat`**：一键关闭脚本模式启动的所有后台观察进程。
- **`test-program-runner.mjs`**：Node.js 运行调度器。
- **`config/test-program.example.json`**：端口与连接地址配置示例。
- **`架构与源码索引.md`**：本测试程序的前后端源码定位与架构解析。

## 运行方式

### 方式一：独立 EXE 版（推荐，开箱即用）
1. 确保主程序（正式版）已在运行（默认主程序后端运行于 `http://127.0.0.1:3003`）。
2. 直接双击本目录中的 **`FlameDetectorTestProgram.exe`**；也可以只复制这个 EXE 到目标电脑。它不需要 Node.js、npm 或源码目录。
3. 如需校验文件完整性，可使用同目录的 **`FlameDetectorTestProgram.exe.sha256`**。
4. 程序将自动拉起观察服务并在浏览器打开界面：
   - **测试前端界面**：`http://127.0.0.1:3005`
   - **测试观察器服务**：`http://127.0.0.1:3004`
5. 数据与归档默认保存在：
   - `%APPDATA%\FlameDetectorTestProgram\data\archives\`
   - `%APPDATA%\FlameDetectorTestProgram\logs\`

### 方式二：脚本版启动（适合二次开发与调试）
1. 必须复制完整的 **`上位机界面原型版`** 项目，不能只复制当前 `测试程序-PLC与数据状态监听` 文件夹；启动器还需要父目录中的 `server`、前端源码和 `node_modules`。
2. 目标电脑需安装 Node.js，并已在项目根目录及 `server` 目录安装 npm 依赖。
3. 双击运行 **`一键启动测试程序(脚本版).bat`**。
4. 控制台将自动检查所需文件，启动观察器后端与测试前端；缺少文件时会显示具体路径和独立 EXE 的使用提示。
5. 测试完成后，可双击 **`一键停止测试程序(脚本版).bat`** 优雅退出。

> 脚本启动器不再通过 `cmd.exe` 嵌套启动 npm 命令，可避免非标准 Windows 系统目录下的 `spawn ... cmd.exe ENOENT` 错误。

## 默认端口与环境变量说明

| 服务 / 目标 | 默认地址 / 端口 | 说明 |
| :--- | :--- | :--- |
| **主程序（被监听对象）** | `http://127.0.0.1:3003` | 主程序后端数据服务 |
| **测试程序前端 UI** | `http://127.0.0.1:3005` | 测试观察程序界面 |
| **测试程序观察器后端** | `http://127.0.0.1:3004` | 测试程序本地只读聚合后端 |

如果主程序使用了自定义端口，可通过环境变量或命令行参数指定：
```cmd
FlameDetectorTestProgram.exe --formal-backend-url http://127.0.0.1:3003 --backend-port 3004 --frontend-port 3005
```

# 测试程序架构与源码索引

测试程序（Test Program Observer）是一个专用于**监听主程序PLC状态、数据状态与阶段归档**的独立旁路测试观察系统。

---

## 1. 架构定位

```
[西门子 PLC / 硬件设备]
        ▲
        │  (S7 读写控制)
        ▼
[正式主程序后端 (Port 3003)] ◄──── [正式主程序前端 UI (Port 3002)]
        │
        │ 只读 HTTP / WebSocket 广播状态流 (/api/field/summary)
        ▼
┌──────────────────────────────────────────────┐
│  测试程序（状态监听与测试观察器）            │
│                                              │
│  - 观察器后端 (Port 3004):                   │
│    · 聚合 PLC 状态 / 探测器数据 / 继电器状态 │
│    · 计算阶段时序与各阶段波形峰值            │
│    · 自动生成测试报告与 JSON 历史归档        │
│                                              │
│  - 测试程序前端 UI (Port 3005):              │
│    · 阶段状态面板与测试计划配置              │
│    · 历史归档列表与详情查看                  │
└──────────────────────────────────────────────┘
```

---

## 2. 源码文件索引

### 前端源码
- **`components/TestProgramApp.tsx`**：测试程序专属的前端界面根组件，提供阶段状态监控卡片、工步计划编辑器、实时波形与归档记录查看器。
- **`index.tsx`**：根据 `VITE_RUNTIME_MODE=test` 环境变量自动挂载 `TestProgramApp`。

### 后端与核心逻辑源码
- **`server/src/test-program-main.ts`**：测试程序后端服务主入口。
- **`server/src/test-program/test-program-server.ts`**：Express + WebSocket 服务，提供测试健康检查、阶段计划配置读取与更新、归档数据查询。
- **`server/src/test-program/test-program-observer.ts`**：连接主程序 `http://127.0.0.1:3003` 的只读客户端，订阅主程序广播的状态流。
- **`server/src/test-program/test-program-tracker.ts`**：工序阶段状态机跟踪器，监控上料、对准、点火、通信等阶段切换与时长统计。
- **`server/src/test-program/test-program-archive.ts`**：数据归档模块，自动输出本地 HTML 报告与 JSON 结构化数据文件。
- **`server/src/test-program/test-program-plan-config.ts`**：测试阶段工步计划的本地存储管理（不影响主程序PLC设置）。

### 单文件 EXE 打包与发布相关
- **`测试程序-PLC与数据状态监听/FlameDetectorTestProgram.exe`**：已编译打包的单文件独立免安装可执行程序。
- **`packaging/test-program-portable/Launcher.cs`**：C# WinExe 启动引导器（内嵌 Node.js 与运行时，释放后自动拉起服务）。
- **`scripts/build-test-program-portable.ps1`**：自动化编译与单文件 EXE 打包脚本。
